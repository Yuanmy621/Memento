## 提交前操作提醒（对齐官方须知）

1. 登录补天 → 提交漏洞 → 选择所属厂商/项目（通用漏洞走通用通道）。
2. 逐字段从上表复制；**GET 注入填完整参数拼接 URL，POST 注入填补充URL+完整数据包（多包打包时描述框只填一个）**。
3. 证据按"四件套"顺序上传，附件单个 ≤5M，材料多时打压缩包。
4. **权重选择**：公益/未注册厂商必选；权重为 0 的厂商务必显式选 0——选错/漏选将驳回。
5. 修复方案认真填写；所属行业/地区按厂商实际情况选。
6. 新用户待审核漏洞上限 5 个，通过 1 条有效漏洞后解除；同一系统同类型漏洞只提交最优一个（超 3 个不再计奖）。
7. 提交前过一遍报告末尾的"人工核验清单"，全部勾选再提交（未经人工验证的 AI 生成漏洞多次提交可能面临封号风险——官方原文）。
